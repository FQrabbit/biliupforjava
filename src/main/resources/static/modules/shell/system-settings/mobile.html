请求与上传
API 请求限速 QPS
限制每秒请求 B 站 API 的次数，防止风控。系统已对各项请求增加合理延迟，此项是全局兜底，无需设置过低。
上传带宽限速
限制上传视频时的最大带宽，0 为不限速。限速只保证最高值不超过设定值，非必要不建议开启，避免影响上传效率。
短时间开播合并 分钟
下播后等待多长时间再投稿，同时间隔内再次开播会算作同一次直播，避免短时间开播下播拆分稿件。
稿件拆分时长分钟
0为关闭，任一阈值达到后从下一分P开新稿；当前完整分P留在原稿件，阈值从下一份新稿件生效；累计视频时长，不计断播间隔
稿件拆分大小GB
0为关闭，任一阈值达到后从下一分P开新稿；当前完整分P留在原稿件，阈值从下一份新稿件生效；1 GB = 1024 MB
上传并发连接 个
限制同时进行的上传连接数，值越小对网络占用越少。多账号同时上传时建议保持较低值，避免网络拥塞影响其他应用。
弹幕节流
弹幕发送间隔 秒
普通弹幕与 SC/上舰高级弹幕共用的全局发送间隔，默认 25 秒。数值过低可能更容易触发风控。
评论发送间隔 秒
SC/上舰列表评论与礼物评论共用的全局发送间隔，默认 25 秒。
